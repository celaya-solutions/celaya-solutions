## How I work

- **Build in public.** The repo is the record. Every project keeps a `CLAUDE.md` change log so the next session — human or agent — starts oriented.
- **Local-first and privacy-first.** Safety logic runs on the edge. Cloud is an enhancement, never a dependency.
- **Ship the thin slice.** Phase gates, not big bangs. A thing that runs beats a thing that's designed.
- **Write it down for the person after you** — including when that person is me, next week.
